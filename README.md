# ESG Ready — 디자인 개선 버전

## 이번 개선 사항
- 더 강한 시각적 위계와 편안한 여백
- 브랜드 컬러, 타이포그래피, 대시보드 미리보기
- 모바일 화면에 대응하는 레이아웃과 메뉴
- 키보드 사용자용 본문 바로가기와 명확한 포커스 표시
- 체크리스트/검색에 레이블 제공 및 동적 HTML 삽입 최소화
- 규제 정보 검색 및 상태 필터, 공식 출처 링크
- 체크리스트 진행률을 현재 브라우저에 저장

## 실행
1. ZIP 압축을 풉니다.
2. `index.html`을 더블클릭해 브라우저에서 확인합니다.
3. GitHub Pages에 공개하려면 `index.html`, `style.css`, `script.js`를 저장소 최상위에 업로드합니다.
4. 저장소 `Settings → Pages → Deploy from a branch → main → /(root) → Save`로 설정합니다.

## 중요
- 이 프로토타입은 법률·회계·공시 자문이 아닙니다.
- 규제 일정/적용 대상은 공식 원문에서 재확인해야 합니다.
- 체크리스트는 브라우저 로컬 저장이므로 계정 간 동기화되지 않습니다.
- 웹폰트는 인터넷 연결 시 Google Fonts에서 불러옵니다.
